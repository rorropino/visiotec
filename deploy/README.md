# VisioTec v2

The corporate website lives in `site/`, separate from existing bounties. The production logo and PHP contact endpoint are retained. Conceptual portfolio graphics are clearly identified; only public links previously tested are shown. GitHub Actions validates HTML structure, Javascript and desktop/mobile browser behavior. On `main`, the deployment requires repository secrets CPANEL_HOST, CPANEL_PORT, CPANEL_USER, CPANEL_PROD_PATH, CPANEL_SSH_KEY and CPANEL_KNOWN_HOSTS; optional CPANEL_SSH_PASSPHRASE. Set these through the authorized GitHub secret interface, never in source. The deployment checks the target entry, preserves existing PHP logic, backs up the changed files outside the public root and restores them on failure. Real contact delivery is not tested by the smoke test; the backend is not modified.
